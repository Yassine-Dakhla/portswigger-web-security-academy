# PortSwigger Web Security Academy

My hands-on learning journey through [PortSwigger Web Security Academy](https://portswigger.net/web-security), a free resource for learning web application security through guided material and practical labs.

## Goals

- Understand common web application vulnerabilities and their root causes.
- Practise HTTP analysis with Burp Suite.
- Develop a repeatable methodology for investigating security issues.
- Learn how to assess impact and explain remediation.
- Build clear, original technical notes as I progress toward bug bounty hunting.

## How I document labs

For each lab, I aim to record:

1. The objective and vulnerability category.
2. The relevant concepts.
3. My investigation and testing methodology.
4. Important request/response observations.
5. The root cause, potential impact, and remediation.
6. What I learned and what I would test next.

I will mark a lab as completed only after I have solved it myself. These notes are for educational purposes and reflect practice in PortSwigger's intentionally vulnerable lab environment.

## Responsible practice

All hands-on testing described here is performed in authorized training labs or on systems for which I have explicit permission. For real bug bounty programs, I will follow the program's scope, rules, and disclosure requirements. I will not publish secrets, session tokens, private program data, or confidential vulnerability details.
